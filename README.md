# 🎮 Rock Paper Scissors

A modern and interactive Rock Paper Scissors web game built using **Python, Flask, HTML, CSS, and JavaScript**. Challenge the computer, keep track of your score, and enjoy a clean, responsive interface.

## 🌐 Live Demo

🔗 https://rockpaperscissors-g0u7.onrender.com/


## ✨ Features

- 🎮 Play Rock, Paper, or Scissors against the computer
- 🤖 Random computer moves
- 🏆 Live score tracking
- ⚡ Instant result display
- 📱 Responsive design for desktop and mobile
- 🎨 Modern user interface

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML5, CSS3, JavaScript
- **Version Control:** Git & GitHub
- **Deployment:** Render

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/himuuu-0301-sketch/RockPaperScissors.git
```

Move into the project directory:

```bash
cd RockPaperScissors
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it:

**Windows**
```bash
.venv\Scripts\activate
```

**Linux/macOS**
```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
